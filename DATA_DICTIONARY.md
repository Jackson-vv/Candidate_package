# Описание данных

## sales_1c.csv

Продажи из 1С.

| Поле | Описание |
|---|---|
| doc_id | идентификатор документа продажи |
| date | дата продажи |
| region | регион |
| chain_id | идентификатор торговой цепочки |
| chain_name | название торговой цепочки |
| customer_id | идентификатор клиента |
| sku_id | идентификатор номенклатуры |
| product_group | товарная группа |
| qty | количество, кг |
| revenue_byn | выручка, BYN |

Особенности:

- есть дубли `doc_id`;
- есть отрицательные продажи — возвраты;
- есть старые SKU вида `SKU_OLD_*`.

## plan.csv

Месячный план продаж.

| Поле | Описание |
|---|---|
| month | месяц плана, формат YYYY-MM |
| region | регион |
| chain_id | идентификатор торговой цепочки |
| chain_name | название торговой цепочки |
| product_group | товарная группа |
| plan_qty | месячный план, кг |
| mon_weight ... sun_weight | веса дней недели |

## sku_links.csv

Связи старой и актуальной номенклатуры.

| Поле | Описание |
|---|---|
| old_sku_id | старая номенклатура |
| current_sku_id | актуальная номенклатура |
| valid_from | дата начала действия связи |
| valid_to | дата окончания действия связи |

Если `valid_to` пустой, связь действует бессрочно.

## product_catalog_optional.csv

Справочник 12 актуальных продуктов. Файл необязательный.

## stock_movements_optional.csv

Движения склада для задания со звездочкой. Файл необязательный.
